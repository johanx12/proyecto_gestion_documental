# Mantenimiento

- Revisar semanalmente el tamaño de `instance/uploads`.
- Ejecutar el script de respaldo antes de cambios importantes.
- No subir `.env`, bases SQLite ni archivos de clientes al repositorio.
- Revisar la bitácora para detectar cargas o eliminaciones inesperadas.
- Antes de activar IA, definir proveedor, presupuesto, protección de datos y pruebas de calidad.
