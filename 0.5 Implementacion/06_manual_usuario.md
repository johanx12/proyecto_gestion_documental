# Manual de usuario

1. Entra a `/registro` y crea una cuenta. La primera cuenta es administradora.
2. Inicia sesión y abre **Nuevo repositorio**.
3. Dentro del repositorio, selecciona un archivo PDF, DOCX o TXT, escribe título, categoría y descripción y pulsa **Cargar**.
4. Consulta documentos desde la tabla, utiliza **Descargar** o edita sus metadatos.
5. Usa **Buscar** para localizar documentos por nombre, categoría, título o descripción.
6. En **IA pendiente** se observa qué funciones quedan reservadas para una futura versión.

Si un archivo no aparece, verifica su extensión, tamaño y que estés usando el usuario propietario o un administrador.
