# Ingeniería de requerimientos

Esta carpeta reúne la definición inicial del Sistema de Gestión Documental (SGD). Los documentos se elaboraron a partir del reto empresarial y de los entregables solicitados en la guía académica.

## Contenido

| Archivo | Propósito |
|---|---|
| 01_contexto_objetivos_alcance.md | Define el problema, la oportunidad, los objetivos y los límites del proyecto. |
| 02_actores_y_personas.md | Identifica actores, permisos y perfiles de usuario. |
| 03_requisitos_y_reglas.md | Especifica requisitos funcionales, no funcionales y reglas de negocio. |
| 04_historias_de_usuario.md | Presenta historias de usuario verificables con criterios de aceptación. |
| 05_casos_de_uso.md | Describe los casos de uso principales y sus flujos. |

## Convenciones

- RF: requisito funcional.
- RNF: requisito no funcional.
- RN: regla de negocio.
- HU: historia de usuario.
- CU: caso de uso.
- ADM: administrador.
- USR: usuario autorizado.

## Estado de la inteligencia artificial

**Pendiente de implementación.**

Las funciones de procesamiento, clasificación, resumen, extracción de información, búsqueda semántica y preguntas en lenguaje natural no forman parte de esta primera versión. Sus archivos y secciones se conservan como marcadores de trabajo futuro, sin describir un comportamiento que aún no existe.
