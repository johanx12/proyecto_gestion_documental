# Datos de prueba

## Cuentas ficticias sugeridas

| Usuario | Rol | Propósito |
|---|---|---|
| `admin_demo` | administrador | Reportes, usuarios y archivo lógico |
| `gestor_demo` | usuario | Carga, búsqueda y consulta |
| `lector_demo` | usuario | Validación de permisos restringidos |

Las contraseñas se deben configurar localmente y nunca escribir en el repositorio.

## Organizaciones ficticias

- Servicios Andinos Demo S.A.S.
- Distribuciones Horizonte de Prueba.
- Cooperativa Académica Central.

## Documentos

La carpeta `11_repositorio_pruebas/datos_prueba` contiene 30 archivos TXT ficticios, distribuidos en tres categorías. Ningún archivo contiene datos personales reales.

## Convenciones

- Fechas: intervalos del año 2026 usados solo como muestra.
- Valores: cantidades simuladas sin relación con transacciones reales.
- Referencias: prefijos `CTR`, `FAC` e `INF`.
- Estados: activo, archivado y restaurado.
- Categorías: contrato, factura e informe.

Para probar extensiones prohibidas se debe crear un archivo temporal sin contenido ejecutable; no se debe guardar malware ni código peligroso en el repositorio.
