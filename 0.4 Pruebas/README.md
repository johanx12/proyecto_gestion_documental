# 0.4 Pruebas

Esta carpeta reúne la planeación de pruebas del prototipo **Portal de Gestión Documental**. Su propósito es dejar una guía reproducible para validar el sistema cuando el código esté instalado en un ambiente de pruebas.

Los documentos no afirman que las pruebas hayan sido ejecutadas. Los estados iniciales se conservan como **No ejecutado** y las tablas describen los resultados esperados.

## Contenido

- `01_plan_de_pruebas.md`: alcance, responsables, ambiente, criterios y cronograma sugerido.
- `02_estrategia_de_pruebas.md`: niveles, tipos, técnicas y manejo de evidencias.
- `03_casos_de_prueba.md`: quince casos funcionales y no funcionales.
- `04_matriz_requisito_prueba.md`: relación entre requisitos y casos.
- `05_resultados_esperados.md`: plantilla de ejecución y comportamiento esperado.
- `06_registro_de_defectos.md`: formato y catálogo inicial de riesgos por comprobar.
- `07_conclusiones_pruebas.md`: conclusiones de planeación y trabajo pendiente.
- `08_datos_de_prueba.md`: datos ficticios permitidos para las validaciones.

## Estado de la integración de IA

Las funciones de inteligencia artificial quedan fuera del alcance de esta versión. Se reserva el identificador `RF-IA-01` para una clasificación o resumen futuro, pero no se configura proveedor, clave, modelo ni llamada externa. Las pruebas asociadas permanecen pendientes hasta una versión posterior.
