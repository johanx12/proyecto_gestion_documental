# Proyecto de gestión documental

Estructura académica basada en la guía del Proyecto Integrador de Desarrollo de Aplicaciones Empresariales de la UTS.

## Estado del proyecto

Esta versión crea la documentación, el desarrollo base, las pruebas planificadas y los archivos de demostración. La inteligencia artificial queda pendiente de implementación por decisión del estudiante. Los archivos relacionados con IA se conservan como plantillas vacías para una fase posterior.

## Estructura

- `0.0 ing de requerimientos`: problema, objetivos, requisitos, historias y casos de uso.
- `0.1 Analisis`: actores, riesgos, priorización y trazabilidad.
- `0.2 Diseño`: arquitectura, datos, API, interfaces y diagramas.
- `0.3 Desarrollo`: código base Flask, base SQLite, almacenamiento y módulo IA pendiente.
- `0.4 Pruebas`: plan, casos, trazabilidad y resultados por completar.
- `0.5 Implementacion`: instalación, despliegue, manuales y mantenimiento.
- `11_repositorio_pruebas`: 30 documentos ficticios organizados en tres categorías.

## Funciones previstas en el desarrollo base

- Autenticación básica.
- Creación de repositorios o carpetas.
- Carga, consulta, descarga y eliminación de PDF, DOCX y TXT.
- Búsqueda por nombre y metadatos.
- Dashboard con conteos del repositorio.
- Registro de estados y errores.

## Inteligencia artificial

Pendiente de implementación. La documentación identifica el flujo y los puntos de integración, pero el código no llama modelos, API ni servicios de IA. No se publica ninguna credencial.

## Fuente de requisitos

La guía PDF proporcionada se utilizó únicamente como referencia. No se copia al repositorio. Consulta `CUMPLIMIENTO_GUIA.md` para ver la correspondencia entre sus entregables y estos archivos.
